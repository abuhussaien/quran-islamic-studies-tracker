# منصة متابعة أعمال الطلاب الرقمية

منصة رقمية شاملة لمتابعة وتقييم أعمال طلاب الصف السادس الابتدائي في مادة القرآن الكريم والتجويد.

## الميزات

### النموذج الأول: متابعة أعمال الطلاب التفصيلي
- تسجيل درجات جميع البنود بشكل منفصل
- حساب متوسط الاختبارين تلقائياً
- حساب المجموع الكلي (الحد الأقصى 100)

### النموذج الثاني: كشف درجات الطلاب النهائي
- عرض ملخص الدرجات النهائية
- المهام الأدائية والمشاركة والتفاعل (40 درجة)
- التقويمات الشفهية والتحريرية (60 درجة)
- المجموع الكلي (100 درجة)

### طرق إدخال البيانات
1. **إدخال يدوي**: إضافة طالب واحد في كل مرة
2. **إضافة دفعة**: إدخال عدة أسماء مرة واحدة
3. **رفع CSV**: استيراد البيانات من ملف Excel/CSV

### ميزات إضافية
- حفظ البيانات تلقائياً في المتصفح (LocalStorage)
- رفع ملفات Excel (.xlsx, .xls) و CSV
- تصدير البيانات إلى ملف Excel
- تصدير البيانات إلى ملف PDF
- حسابات تلقائية في الوقت الفعلي
- زر نشر النتائج
- تصميم متجاوب للجوال والأيباد

| جودة الحفظ | 7 |
| واجبات | 15 |

| المشاركة والتفاعل | 15 |
| الاختبار التحريري الأول | 40 |
| الاختبار التحريري الثاني | 40 |
| **متوسط الاختبارين** | **40** |
| **المجموع الكلي** | **100** |

## طريقة حساب الدرجات

### النموذج الأول
```
متوسط الاختبارين = (الاختبار الأول + الاختبار الثاني) / 2   [الحد الأقصى: 40]

البنود الأخرى (60 درجة):
- صحة التلاوة (8) + تطبيقات التجويد (5) + جودة الحفظ (7) = 20
- واجبات (15) + مهام أدائية (10) + المشاركة والتفاعل (15) = 40

المجموع الكلي = متوسط الاختبارين (40) + البنود الأخرى (60) = 100
```

### النموذج الثاني (كشف الدرجات النهائي)
يحتوي على 5 أعمدة فقط:
1. رقم الطالب
2. اسم الطالب
3. المهام الأدائية والمشاركة والتفاعل (40)
4. تقويمات شفهية وتحريرية (60)
5. المجموع (100) = العمود 3 + العمود 4

```
المجموع = المهام والمشاركة + التقويمات
```

## طريقة التشغيل

### الطريقة الأولى: فتح مباشر
افتح ملف `index.html` في أي متصفح حديث.

### الطريقة الثانية: خادم محلي
```bash
python app.py
```
ثم افتح `http://localhost:5000` في المتصفح.

### الطريقة الثالثة: خادم Python بسيط
```bash
python -m http.server 5000
```
